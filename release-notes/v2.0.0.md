## Changes in 2.0.0
- **New look.** The window is rebuilt on Avalonia with the same layout as the other apps: a header with the status line, tabs along the top (Clicker, Hold, Settings), and setting cards with toggle switches.
- **Settings.** Settings now has General (startup and appearance) and Profiles tabs. The dark mode switch is under General > Appearance and still applies at once and is remembered. Your saved settings are read as before.
- **Notices.** The "clicking started" notice is now a small click-through message at the top of the screen instead of a Windows balloon. It also shows when the window is hidden in the tray.
- **Hotkeys.** Setting a key now reads it from the keyboard hook, so any key can be chosen, and names such as Esc, Page Up and F6 are shown plainly.
- The setup installer and portable zip are built as before.
