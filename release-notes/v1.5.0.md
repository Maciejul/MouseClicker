## Changes in 1.5.0
Reliability and safety release.

- **Settings are safer.** Saved atomically; an unreadable settings file is kept as `settings.json.bak` instead of being overwritten. Saving waits until you stop typing, so the hotkeys are never held up by disk writes. Enum values are saved by name.
- **Profile names** are now matched without regard to case everywhere (save, switch, delete, next-profile key). Names are trimmed, an empty name gets the first free "Profile N", and duplicate or blank names in an old file are repaired on load.
- **Only one copy runs.** Starting the app again brings the open window forward.
- **Stops when you leave.** Clicking and holds stop on lock, sign-out, disconnect and sleep. A crash releases any held key or button first and is logged to `%APPDATA%\MouseClicker\error.log`.
- **Games:** held keys are sent as scan codes, so games that read DirectInput or raw input see them.
- **Multi-monitor:** per-monitor DPI awareness, so captured points and window offsets land in the right place.
- Clicking stops with a clear message when the target window is minimized or runs as administrator; capturing an administrator window warns you.
- Stopping the clicker is immediate, and short intervals are more accurate.
- Number boxes accept digits only and show the value actually in use when you leave them.
- A warning appears if Windows refuses the keyboard hook.
- Internals: tray, autostart and the hold-trigger logic are separate classes with unit tests; CI runs the tests on every push and pull request.
